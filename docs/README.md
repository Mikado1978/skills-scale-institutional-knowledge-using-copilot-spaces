# OctoAcme Project Management Docs

Bienvenido/a. Esta carpeta reúne la documentación viva sobre los procesos de gestión de proyectos de OctoAcme para facilitar la incorporación de nuevos miembros, difundir buenas prácticas y asegurar una ejecución consistente de proyectos.

## Resumen del proceso de gestión de proyectos

OctoAcme gestiona sus proyectos por medio de un ciclo repetible que garantiza alineamiento, entrega iterativa y mejora continua:

1. **Initiation** — Definición del problema, objetivos, métricas de éxito y stakeholders.
2. **Planning** — Desglose del trabajo, gestión de riesgos y dependencias, y construcción del backlog priorizado.
3. **Execution & Tracking** — Uso de tableros, checklists y standups regulares para impulsar el progreso y resolver bloqueos.
4. **Release & Deployment** — Pasos estandarizados y listas de verificación para asegurar implementaciones seguras y transparentes.
5. **Retrospective** — Revisión de resultados, aprendizajes y mejoras al proceso.

**Roles** (Project Manager, Product Manager, Developers, QA, Stakeholders) y plantillas o checklists clave se definen en cada documento de proceso correspondiente.
